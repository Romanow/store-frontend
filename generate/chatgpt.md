Ты выступаешь в роли frontend разработчика на стеке react + redux.
Нужно разработать сайт интернет-магазина. Дан OpenAPI в формате json, в нем 6 операций:

* `GET /api/v1/store/orders` – получить список заказов пользователя.
* `GET /api/v1/store/{orderUid}` – информация по конкретному заказу.
* `POST /api/v1/store/{orderUid}/warranty` – запрос гарантии по заказу.
* `POST /api/v1/store/purchase` – выполнить покупку.
* `POST /api/v1/store/{orderUid}/refund` – вернуть заказ.
* `GET /api/v1/warehouse/items` – информация о доступных товарах.

Авторизация пользователя выполняется по протоколу OIDC через Identity Provider Auth0, на backend передается JWT токен в
заголовке Authorization.

Сайт содержит 3 страницы:

* Страница товаров, она доступна неавторизованному пользователю. Данные на со страницы заказов загружаются с endpoint
  `GET /api/v1/warehouse/items`.
* Пользователь может добавлять товары в корзину. После того, как он переходит в корзину, требуется авторизация (переход
  на Auth0).
* Пользователь может оформить заказ (запрос `POST /api/v1/store/purchase`)
* После этого пользователь переходит на страницу своих заказов (`GET /api/v1/store/orders`), там выводится общая
  информация о заказах.
* Если пользователь хочет посмотреть конкретную информацию по заказу, он нажимает на него и переходит на страницу с
  информацией по заказу (`GET /api/v1/store/{orderUid}`).
* На этой странице он может запросить гарантию по заказу (`POST /api/v1/store/{orderUid}/warranty`) или вернуть товар (
  `POST /api/v1/store/{orderUid}/refund`).

Переход между страницами выполняется с помощью react-router.

Напиши сайт с использованием React, Redux на языке TypeScript.
